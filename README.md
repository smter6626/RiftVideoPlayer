# Rift Video Player（本地定制版）

## 1. 源仓库

- 源项目：[rafaelo96/RiftVideoPlayer](https://github.com/rafaelo96/RiftVideoPlayer)
- 本地定制仓库：[smter6626/RiftVideoPlayer](https://github.com/smter6626/RiftVideoPlayer)
- 本仓库基于源项目开发，面向本机实际播放体验进行定制；不会自动与源仓库的后续变更保持同步。

## 2. 本地的差异化改造

- **修复 Finder 双击视频时出现两个 Rift 窗口**：主界面改为唯一的单窗口场景，移除额外的 fallback window，并让待打开的视频 URL 只被消费一次。双击视频后只保留一个播放窗口。
- **修复 Frame+ MEMC 资源加载**：按照 macOS/SwiftPM Bundle 语义查找 `Rift_Rift.bundle` 的实际资源目录，同时兼容旧的扁平资源布局，使 `FramePlusMEMC.metal` 能被正确找到并加载，避免 Frame+ 全部退化为 crossfade fallback。
- **增加 Frame+ 诊断能力**：通过默认关闭的 `RIFT_FRAME_DIAGNOSTICS=1` 环境变量，可记录 MEMC 初始化、资源路径、生成/回退计数、渲染与呈现帧率、GPU/CPU 耗时以及 `currentDrawable` 等性能数据；正常启动时不启用这些诊断。
- **控制栏支持按比例缩放**：鼠标移动到控制栏四边时显示对应方向的缩放光标，可从任意边按比例调整整体大小，范围为 `65%–135%`，并限制在窗口安全边界内。
- **控制栏支持稳定拖动**：使用顶部中央的独立拖动滑块移动控制栏，增宽了滑块及其可操作区域；移动和缩放采用统一交互状态，避免手势冲突、自动吸附、突然跳远或移出窗口。
- **优化控制栏交互联动**：拖动或缩放期间暂停自动隐藏，操作结束后恢复；窗口尺寸变化时重新约束控制栏位置；字幕底部留白会根据控制栏当前位置和尺寸动态调整。
- **调整控制栏默认状态**：应用启动后，控制栏默认以最小 `65%` 尺寸显示在窗口最左下角，并保留 `8pt` 安全边距；取消双击控制栏自动复位功能。
- **补充回归测试与本地文件忽略规则**：加入资源 Bundle 布局测试，并忽略本地诊断脚本和编辑器备份文件。
